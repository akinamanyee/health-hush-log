# 封面缺少「進入」按鈕 — 修復計劃

## 問題診斷（已查證）

- 目前封面 `src/routes/index.tsx` 只顯示整張圖片，整幅圖可點擊進入，但**畫面上沒有任何可見的「進入」按鈕**。
- 之前以為圖片內本身印有按鈕，所以移除了重疊按鈕；但核對現用的 `front-page-2.jpg`（即你最新提供的封面圖），圖內只有標題、標語和兩個圖示，**沒有印刷按鈕**。
- 結果：45+ 使用者看不到下一步該按哪裡 — 這正是你發現的問題。

## 修復方案（只動封面，其他邏輯與格式不變）

在 `src/routes/index.tsx` 加回一個清晰可見的「進入」按鈕：

```text
┌──────────────────────────────┐
│              [私隱與資料使用] │  ← 保留不變（右上角）
│                              │
│        護心計劃（圖內）       │
│   守護您的心腦血管健康        │
│        開始檢測（圖內）       │
│                              │
│     [心圖示]   [急救箱圖示]   │
│                              │
│        ┌──────────┐          │
│        │   進入    │          │  ← 新增：深藍色大按鈕
│        └──────────┘          │     置於兩圖示正下方
└──────────────────────────────┘
```

具體做法：

1. **新增可見「進入」按鈕**：深藍色（與圖內標題 navy 一致）、圓角、白字「進入」，置於兩個圖示正下方、圖片下緣上方，垂直置中對齊兩圖示的中線。
2. **位置用百分比定位**（約在畫面高度 82–88% 處），桌機與手機都穩定落在圖示下方，不遮擋圖內文字與圖示。
3. **45+ 友善尺寸**：按鈕高度至少 56px、字級 20px 以上、寬度充裕、點擊範圍大；帶輕微陰影使其在淺綠背景上清晰突出。
4. **保留不變**：右上角「私隱與資料使用」連結、整幅封面圖仍可點擊進入（作為額外便利）、`/logbook` 目的地、所有其他頁面與邏輯。
5. **驗證**：桌機與手機尺寸截圖確認按鈕位置在圖示正下方、間距均勻；點擊按鈕確認進入 `/logbook`。
